# Тестирование учебного сайта Stellar Burgers

В проекте написаны автотесты для сервиса Stellar Burgers — космического фастфуда, где можно собрать и заказать бургер из необычных ингредиентов.

# Описание тестов

test_registration.py: проверка успешной регистрации и ошибки регистрации при введении пароля меньше 6 символов
test_authorization.py: проверка Входа по кнопке «Войти в аккаунт» на главной, через кнопку "Личный кабинет", через кнопку в форме регистрации, через кнопку в форме восстановление пароля
test_personal_account: проверка перехода по клику на "Личный кабинет"
test_click_constructor: проверка перехода из личного кабинета по клику на Конструктор
test_click_logo_SB: проверка перехода из личного кабинета по клику на логотип Stellar Burgers
test_logout_personal_account: проверка выода по кнопке "Выход" в Личном кабинете
test_transition: проверка, что работают переходы к разделам "Булки", "Соусы", "Начинки"

# Запуск тестов

Для запуска тестов с подробным выводом:

pytest -v tests.py
